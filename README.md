Project Overview:

This project applies Python-based data analysis and machine learning to investigate health-related factors associated with COVID-19 risk categories.

The analysis focuses on clinical and health conditions including diabetes, hypertension, cardiovascular disease, COPD, asthma, and chronic renal disease, followed by machine-learning-based prediction of COVID-19 risk categories.

Objective:

The main objectives of this project are to:

Analyze the distribution of COVID-19 risk categories.

Examine the association between major health conditions and risk categories.

Investigate correlations among health-risk factors.

Identify patterns in patients with different risk levels.

Develop a machine-learning classification model for COVID-19 risk prediction.

Evaluate model performance using a confusion matrix.

Tools and Technologies:

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

Exploratory Data Analysis:Exploratory analysis was performed to understand the distribution of COVID-19 risk categories and the prevalence of different health conditions.

Model Evaluation:
The confusion matrix provides more detailed information than accuracy alone because it shows which risk categories were correctly or incorrectly predicted.

Conclusion:

This project demonstrates the application of data science and machine learning to biomedical and healthcare data.
The project provides practical experience in applying Python and machine learning techniques to health-related datasets and demonstrates
how computational approaches can be used to investigate patterns associated with disease risk.
